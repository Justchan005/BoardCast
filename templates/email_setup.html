Connect Gmail for preview emails

Connect a Gmail or Google Workspace account once on this computer. Student Affairs can then send a copy of an edition to one chosen email address. Normal local publishing still saves messages to the outbox.

The sender is the Google account you choose during the connection step. BoardCast requests permission to send email only; it does not read your mailbox or ask for your Google password.

1 Prepare the Google project

  1. Open your project in the Google Cloud console and enable the Gmail API.
  2. Configure Google Auth platform branding and audience. For a personal Gmail account, use an external audience. While the app is in testing, add the sender's Google account as a test user. A Workspace organisation may require its administrator's approval.
  3. Under Clients, create an OAuth client with application type Desktop app. Download its JSON file as credentials.json into the BoardCast project folder, beside README.md.

Follow the official Gmail setup instructions if the console labels differ. This setup authorises the sender; Gemini API keys do not grant email access.

2 Connect the sender on this computer

Open PowerShell in the BoardCast project folder. Install the updated backend requirements and run the connection helper:

.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
.\.venv\Scripts\python.exe -m scripts.get_gmail_token

A Google sign-in window opens. Choose the intended sender and review the requested send-email permission. On completion, the helper saves token.json in the project folder. Keep both JSON files private; the default filenames are excluded from Git.

If you use a custom token location, set GMAIL_TOKEN_FILE on the server and restart BoardCast. An existing GMAIL_TOKEN_JSON setting takes precedence over the file.

3 Send a preview

  1. Return to Student Affairs, expand Send real email preview, and select Refresh connection.
  2. Build a local preview with approved submissions, then check it using Read edition. Save any template changes.
  3. Enter one recipient address, tick the confirmation and choose Send real email. The message is labelled as a preview and the posters are included.

Gmail accepting a message does not guarantee inbox delivery. Check the recipient's inbox or spam folder. If the app reports an uncertain outcome, check the sender's Sent folder before trying again; the app does not automatically resend that preview.

What stays local

The preview does not subscribe its recipient or change an item's publication status. Local-only calendar and web-edition links are omitted; approved registration links open their original destinations. The website remains on this computer.

When Google access expires or is revoked, run the connection helper again and refresh the connection. Never paste credentials into the recipient field or share them in screenshots.
