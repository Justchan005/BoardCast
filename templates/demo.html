Who does what

The model reads and advises. Code enforces the rules. A person makes every publishing decision.

  1. Human
    Club rep uploads a posteror types the details for a text-only notice.
  2. Model
    Gemini reads the poster into a fixed schemaMissing facts stay empty. QR codes are decoded in code, never guessed by the model.
  3. Code
    Fixed checks run on the confirmed detailsRequired fields, past dates, link safety, consent. Problems send it back to the club.
  4. Agent
    The pre-review agent chooses which checks to runA second read of the poster, a duplicate search, a link check. Fixed rules can overrule its verdict; it cannot approve, reject or edit.
  5. Human
    Student Affairs approves or returns itPoints raised by the agent must be acknowledged before an approval goes through.
  6. System
    Campus Weekly is built and deliveredGemini only picks which event leads. Every published word comes from approved fields.
